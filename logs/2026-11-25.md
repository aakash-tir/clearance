# 2026-11-25

## Checked Inkling 2 Mini (Thinking Machines) as a model option, deferred to M5

**What we did:** Followed up a newsletter lead about a "26B open-source model from
Thinking Machines that runs in 16 GB". Confirmed it is `thinkingmachines/Inkling-2-Mini`
on Hugging Face (26.4B params, Apache-2.0, released 2026-11-17, actively updated). Added it
to `docs/future.md` under a new **Models** section as a candidate for the M5 generator
comparison. Docs-only, so no code, graph or diagram change.

**The reason:** Clearance lets a company pick any open-weight model, so a permissively
licensed 26B model is worth tracking. But it can't be tested usefully yet. (1) The project
has no model client, retrieval or prompt builder until M4/M5, so there is nothing to run the
"answers only from allowed documents" checks against. (2) Evidence for the hardware claim:
the model card says the checkpoint is "about 20GB" with "32GB or more of VRAM recommended".
The Ollama tags are 18–20 GB, and Ollama support is listed "on Apple Silicon". The dev GPU
(RTX 5070 Ti Laptop) has 12 GB of VRAM, so "16 GB" is wrong for this machine.

**How it was solved:** We didn't pull the weights or change the config. Swapping the model
is already one setting (`CLEARANCE_CHAT_MODEL`). The backlog entry lists what the M5
comparison should measure. It also records why a model refusal is only a UX check: access
is enforced by the database, so forbidden chunks never reach the model.
